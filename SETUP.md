# MikuOS — полная инструкция по установке и запуску

Здесь собрано всё, что нужно поставить, чтобы MikuOS заработала целиком: чат, память, персонаж на
рабочем столе, голос (распознавание + синтез + голос Мику через Applio), Steam и Spotify.
Обязательны только пункты 1–3; остальное — по желанию, без них MikuOS просто работает без этой
функции.

## Коротко

```
1. Windows 10/11 x64
2. LM Studio + модель Мику (загружена или скачана в LM Studio)
3. uv (или Python 3.12)
4. run_mikuos.bat -Install        ← ставит всё остальное для MikuOS
5. (по желанию) спрайты в assets/sprites/, Applio + RVC-модель Мику, Steam, Spotify, микрофон
6. run_mikuos.bat                 ← запуск
```

## 1. Что нужно установить

| # | Программа | Обязательно? | Зачем | Где взять |
|---|---|---|---|---|
| 1 | **Windows 10/11 x64** | да | MikuOS использует Win32 API (окна, горячие клавиши, UI Automation) | — |
| 2 | **LM Studio** | да | «мозг» Мику: в нём работает языковая модель | <https://lmstudio.ai> |
| 3 | **Модель для LM Studio** | да | у автора — Gemma 4 E4B, дообученная под Мику; подойдёт любая модель с tool calling | загружается в LM Studio |
| 4 | **uv** (или Python 3.12) | да | создаёт отдельное окружение `.venv` для MikuOS | <https://docs.astral.sh/uv/> |
| 5 | **Спрайты Мику** | желательно | пиксельная Мику на рабочем столе; без них — векторная заглушка | ваши файлы → `assets/sprites/` |
| 6 | **Микрофон и динамики/наушники** | для голоса | говорить с Мику и слышать её | — |
| 7 | **Applio** + **RVC-модель Мику** | для голоса Мику | превращает голос Silero в голос Мику | <https://applio.org>; модель — ваша (обучена или импортирована в Applio) |
| 8 | **Видеокарта NVIDIA** | желательно | LM Studio и Applio быстрее на GPU (у автора RTX 3060 Ti, 8 ГБ) | — |
| 9 | **Steam** | по желанию | запуск игр по просьбе | <https://store.steampowered.com> |
| 10 | **Spotify** (приложение для ПК) | по желанию | «что играет», пауза, следующий трек, включить трек по названию | <https://www.spotify.com/download> |
| 11 | **Blender** (5.x) | только для 3D-варианта | один раз собрать 3D-модель; при спрайтах не нужен | <https://www.blender.org> |

Всё остальное MikuOS ставит или скачивает сама (раздел 3).

## 2. Порядок установки

### 2.1 LM Studio и модель

1. Установите LM Studio и загрузите в неё модель (вкладка «My Models»).
2. Больше ничего делать не нужно. Скрипт запуска сам включает сервер LM Studio (`lms server start`,
   порт `1234`) и загружает модель, в имени которой есть `miku`, с контекстом 8192 токенов.
   Другие модели он не скачивает.
3. Свою модель можно указать явно: `config/settings.json` → `lmstudio.model` (id модели) или
   `lmstudio.model_preference` (часть имени).

### 2.2 Окружение MikuOS

В папке проекта, в PowerShell:

```bash
.\run_mikuos.bat -Install
```

Скрипт:

1. Создаёт `.venv` на Python 3.12 (через uv, иначе через `py -3.12`).
2. Ставит `requirements.txt`: FastAPI, uvicorn, httpx, PySide6, pywin32, comtypes, jsonschema,
   psutil, pytest.
3. Ставит голосовые зависимости `requirements-voice.txt`: faster-whisper, sounddevice, numpy.
4. Ставит `torch` 2.14.1 в CPU-сборке. Версия для видеокарты не нужна: Silero и Whisper работают на
   процессоре, а видеопамять остаётся для LM Studio и Applio.

Если голосовые пакеты не поставились, MikuOS работает без голоса (в консоли будет предупреждение).

> В PowerShell перед именем файла нужно писать `.\` (`.\run_mikuos.bat`), иначе PowerShell его не
> найдёт.

### 2.3 Спрайты

Положите в `assets/sprites/` два файла:

- `miku_sheet.png` — лист спрайтов на однотонном фоне;
- `miku_idle.gif` — анимация ожидания.

Нарезка на кадры — автоматически при первом запуске (подробнее — в README, раздел «2D-спрайты»).

### 2.4 Applio — голос Мику (RVC)

Цепочка голоса:

```
текст ответа → Silero (русская речь, голос xenia) → Applio / RVC-модель Мику → динамики
```

1. **Установите Applio** (настольное приложение). MikuOS ищет его в `%LOCALAPPDATA%\Applio`; это
   папка установки по умолчанию.
2. **Добавьте RVC-модель Мику в Applio**: обучите её во вкладке «Обучение» или импортируйте готовую.
   Модель должна оказаться в `%LOCALAPPDATA%\Applio\data\runtime\logs\<имя>\<имя>.pth`, индекс (если
   есть) — там же, в `logs\…\*.index`.
3. **Готово.** MikuOS сама:
   - находит первую модель `.pth`, в имени которой есть `miku`;
   - подбирает к ней индекс с тем же именем (`MikuAI_e210_s6300.pth` → `…MikuAI_v2.index`);
   - берёт параметры (высота тона, метод F0, index rate, protect), сохранённые для этой модели в
     Applio (`data\model-presets.json`).

Само окно Applio открывать **не нужно**. MikuOS запускает Python из Applio
(`data\runtime\.venv`) в фоновом процессе `mikuos/voice/applio_worker.py`: он держит модель
загруженной на видеокарте и переводит каждую фразу Silero в голос модели. Если Applio нет, модель не
найдена или конвертация упала, Мику говорит обычным голосом Silero, а ошибка видна в
`GET /api/voice` → `rvc.error` и в логе.

Настройки — `config/settings.json` → `voice.rvc`:

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | `false` — всегда чистый Silero |
| `applio_dir` | `""` | папка Applio (`""` = `%LOCALAPPDATA%\Applio`) |
| `model` | `""` | путь к `.pth` (абсолютный или от `Applio\data\runtime`); `""` = поиск по `model_match` |
| `model_match` | `"miku"` | какое слово искать в имени модели |
| `index` | `""` | путь к `.index`; `""` = индекс с именем модели |
| `pitch`, `f0_method`, `index_rate`, `protect` | `null` | `null` = как сохранено в Applio, иначе 0 / `rmvpe` / 0.5 / 0.5 |
| `timeout_s` | `30` | сколько ждать одну фразу, потом — голос Silero |
| `start_timeout_s`, `warmup_timeout_s` | `120`, `180` | запуск процесса и первая «прогревочная» фраза |

Высота голоса: Silero `xenia` — женский голос. Если результат звучит низко или высоко, поменяйте
`pitch` (в полутонах, например `2` или `-2`) или пресет модели в Applio.

**Видеопамять.** На RTX 3060 Ti (8 ГБ) с загруженной моделью Мику в LM Studio занято около 5,4 ГБ,
вместе с Applio — около 6,4 ГБ. Одновременно с MikuOS не включайте в Applio режим «реального
времени»: это ещё одна копия модели в видеопамяти. К тому же у Applio своя горячая клавиша
`Ctrl+Alt+V`, а это запасная клавиша голоса MikuOS — кто запустится первым, тот её и займёт.

**Лицензия.** RVC-модель — ваш файл, в репозиторий она не входит. Не публикуйте её вместе с
проектом: голос Мику принадлежит Crypton Future Media.

### 2.5 Steam и Spotify

- **Steam** находится автоматически через реестр (по умолчанию
  `C:\Program Files (x86)\Steam\steam.exe`). Удаление игр — только после вашего подтверждения.
- **Spotify** — обычное приложение для ПК. Ни вход в аккаунт со стороны MikuOS, ни ключи Web API
  не нужны: управление идёт через окно Spotify.

## 3. Что скачивается автоматически (один раз)

| Что | Размер | Откуда | Куда |
|---|---|---|---|
| Python-пакеты MikuOS | ~1,5 ГБ (вместе с torch) | PyPI, download.pytorch.org | `.venv/` |
| faster-whisper `small` (распознавание) | ~460 МБ | Hugging Face | `data/models/whisper/` |
| Silero `v4_ru` (синтез) | ~40 МБ | models.silero.ai | `data/models/silero/` |

Applio и RVC-модель MikuOS не скачивает: она использует то, что уже установлено у вас.

## 4. Запуск

```bash
.\run_mikuos.bat
```

Ярлык на рабочий стол создаёт `.\run_mikuos.bat -Shortcut`.

Что происходит при запуске:

1. Включается сервер LM Studio и загружается модель (если не загружена).
2. Стартует backend `127.0.0.1:8765`.
3. Загружаются Whisper и Silero.
4. Запускается и «прогревается» Applio. Первый раз после установки это ~30 с (видеокарта
   компилирует ядра), дальше ~10 с.
5. Появляется Мику на рабочем столе и значок в трее.

Другие режимы: `-Cli` (чат в терминале), `-BackendOnly`, `-Test` (автотесты).

### Голос

| Действие | Как |
|---|---|
| Сказать Мику | `Ctrl+Alt+Space`; если занято — `Ctrl+Alt+V` (фактическая клавиша — в меню), кнопка 🎤 в чате или пункт меню |
| Закончить фразу | пауза ~1,2 с или повторное нажатие |
| Перебить Мику | нажать клавишу голоса, пока она говорит |
| Аварийная остановка | `Ctrl+Alt+M` (или `Ctrl+Alt+Shift+M`): закрывает микрофон и обрывает речь |

Микрофон включается только вашим нажатием, звук нигде не сохраняется.

## 5. Проверка, что всё работает

```bash
.\run_mikuos.bat -Test
```

Состояние голоса — `GET http://127.0.0.1:8765/api/voice`, нужен заголовок `X-MikuOS-Token` из
`data/runtime/token`. В поле `rvc` видно:

- найдена ли модель (`available`);
- запущен ли процесс Applio (`running`);
- последняя ошибка (`error`).

Что проверено на машине автора (25.10.2026):

- Конвертация Silero → Applio (модель `MikuAI_e210_s6300` + индекс):
  - первая фраза после установки — 34 с (прогрев);
  - дальше — около 1 с на фразу в 4,5 с;
  - короткие ответы — 0,3 с.
- Ответ в чате реально озвучен через RVC внутри работающего backend (статус `rvc.error = null`).
- Whisper распознаёт сконвертированный голос: «мику, включи следующий тик» вместо «…трек» — RVC
  немного смазывает отдельные слова.
- Если Applio не работает, звучит голос Silero (автотест).

Не проверено: как это звучит на слух (тесты слушают только «машиной»), запись с реального
микрофона, нажатие горячей клавиши руками.

## 6. Частые проблемы

| Симптом | Причина / решение |
|---|---|
| PowerShell: «не распознано как имя командлета» | пишите `.\run_mikuos.bat`, а не `run_mikuos.bat` |
| Мику не отвечает, точка 🟡 | LM Studio не запущена или модель выгружена — откройте LM Studio или перезапустите MikuOS |
| Голос Silero вместо Мику | Applio не в `%LOCALAPPDATA%\Applio` (укажите `voice.rvc.applio_dir`), в имени модели нет `miku` (укажите `voice.rvc.model`) или ошибка — смотрите `rvc.error` и `data/tmp/rvc/applio_worker.log` |
| Первая фраза после запуска долгая | идёт прогрев Applio (до ~30 с), дальше быстро |
| Не хватает видеопамяти | закройте режим реального времени Applio и другие GPU-программы или уменьшите контекст модели в LM Studio |
| Горячая клавиша голоса не работает | её заняла другая программа — фактическая клавиша показана в меню Мику; поменяйте `voice.hotkey` |
| Нет голоса вообще | `.\run_mikuos.bat -Install` (голосовые пакеты), проверьте устройство вывода звука по умолчанию в Windows |

## 7. Где что лежит

```
config/settings.json                 все настройки (voice.rvc — голос через Applio)
data/mikuos.db                       память
data/models/                         Whisper и Silero
data/tmp/rvc/applio_worker.log       лог процесса Applio
mikuos/voice/rvc.py                  поиск Applio и модели, обмен с процессом
mikuos/voice/applio_worker.py        процесс внутри Python Applio
%LOCALAPPDATA%\Applio\data\runtime\logs\   ваши RVC-модели (.pth, .index)
```
